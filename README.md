# Agriculture Helper Chatbot Using Deep Learning

**AgriSathi** is a responsive agriculture-assistance website concept designed to make common farming information easier to explore. This repository currently contains a front-end demonstration built with HTML, CSS and vanilla JavaScript.

## Features in this version

- Responsive dashboard layout for desktop, tablet and mobile.
- Agriculture Q&A interface with a small set of prepared, rule-based responses.
- Crop suggestion interface using selected soil type, season and water availability.
- Leaf image upload with local preview.
- Links to selected official Indian agriculture resources.
- No build tools or package installation required.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. For local development, you may use the VS Code Live Server extension.

## Publish with GitHub Pages

1. Push the project files to the root of the `main` branch.
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for the deployment to finish. GitHub will show the published site URL in the Pages settings.

## Important project status and limitations

This is currently a **front-end prototype**, not a complete trained deep-learning application.

- Chatbot replies are selected from predefined JavaScript examples; there is no trained NLP model or live AI service.
- Crop suggestions are illustrative rule-based examples; they are not generated by a trained crop recommendation model and should not be used as agronomic advice.
- The leaf image feature only previews the uploaded image in the browser. It does not detect or diagnose plant diseases.
- There is no backend, authentication, database, live weather integration or cloud image storage in this version.

For real farming decisions, verify information with a soil test, local agricultural extension officers and current government advisories. Do not apply pesticides or fertilizers solely on the basis of this demo.
